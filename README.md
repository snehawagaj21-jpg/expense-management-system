# Personal Expense Management System

A Python-based desktop application for managing personal income and expenses. The system uses Tkinter for the graphical interface and SQLite for storing transaction data.

## Features

- Add Income
- Add Expense
- View Transactions
- Search and Filter Transactions
- Update Transactions
- Delete Transactions
- Automatic Balance Calculation
- Budget and Spending Limit
- Budget Warning
- Monthly Summary
- Monthly Spending Comparison
- Reports and Charts
- Pie Chart
- Bar Chart
- Histogram
- Line Chart
- Scatter / Dot Chart
- AI Spending Suggestions
- Financial Goals

## Technologies Used

- Python
- Tkinter
- SQLite
- Matplotlib
